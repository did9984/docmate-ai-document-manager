応募書類を
安全に管理できるポートフォリオサービス

DocMateは、履歴書・職務経歴書・ポートフォリオ資料などの応募書類を管理する Java + Spring Boot ベースのポートフォリオWebサービスです。
txtファイルを対象に、AI要約・AI書類レビュー機能を利用できます。

ログインする 会員登録する

サービス概要

  • 応募書類をアップロードして管理
  • ユーザーごとに書類を安全に保存
  • アップロード済み書類の一覧表示・ダウンロード・削除
  • txtファイルを対象にAI要約・AI書類レビューを利用可能

主な機能

📄 応募書類管理

履歴書、職務経歴書、ポートフォリオ資料などをアップロードして管理できます。

🔐 ユーザー別管理

ログイン中のユーザーごとに書類を管理し、他のユーザーの書類にはアクセスできない構成です。

🤖 AI要約・AI書類レビュー

txtファイルを対象に、応募書類の要約や改善ポイントを確認できます。
